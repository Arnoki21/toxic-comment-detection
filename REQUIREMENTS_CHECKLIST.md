## Official Experiment Summary

The completed official-data comparison selected `word_char_tfidf_lr` with ROC-AUC **0.9813**, precision **0.7144**, recall **0.8741**, and F1 **0.7862**. The official dataset itself is intentionally ignored by Git; the README provides the required Kaggle source link.

## Optional Extension

`python -m src.cli compare --data data/raw/train.csv --include-bow` adds a Bag-of-Words Logistic Regression baseline. A Transformer experiment remains an optional extension rather than a requirement for the selected topic.
